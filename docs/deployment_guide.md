# Production Deployment Guide

This guide explains how to publish the DMYSC system to the internet.

## Hosting Options

### 1. GitHub Pages (Recommended)
Since you already have a `CNAME` file pointing to `dmyc.space`, GitHub Pages is the most likely intended host.

**Steps:**
1. Upload your code to a GitHub repository.
2. Go to **Settings** > **Pages**.
3. Select the `main` branch as the source.
4. Ensure the Custom Domain is set to `dmyc.space`.
5. Enable **Enforce HTTPS**.

### 2. Vercel / Netlify
These platforms offer automatic builds and are very easy to use for static sites.

**Steps:**
1. Connect your GitHub repository to Vercel/Netlify.
2. They will automatically detect the static files and deploy them.
3. Add your domain in the platform's Dashboard.

## Critical Pre-Launch Checklist

### 🛡️ Supabase Security (RLS)
Before going live, you **MUST** enable Row Level Security on all tables in your Supabase Dashboard.
1. Go to **Authentication** > **Policies**.
2. Click **Enable RLS** on every table (e.g., `members`, `payments`, `quick_links`).
3. Create policies to allow:
   - Users to `SELECT` and `UPDATE` their own data.
   - Admins to `SELECT`, `INSERT`, `UPDATE`, and `DELETE` all data.

### 🌐 Domain Configuration
Ensure your domain (`dmyc.space`) is correctly pointing to the hosting provider's IP addresses (A records) or CNAME record.
